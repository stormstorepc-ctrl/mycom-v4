# QA 작업 기록 — 2026-08-23

이번 회차에서 코드상 확인 후 수정한 항목:

1. 예약 생성 시 승인/활성 업체 여부 검증
2. 예약의 quote_id가 로그인 고객 소유인지 검증
3. bid_id가 해당 고객/업체/견적에 연결되는지 검증
4. 과거 날짜 예약 차단
5. 동일 업체/동일 시간 중복 예약 차단 유지
6. 고객의 직접 예약 취소에서도 업체 알림 생성
7. 입찰 금액을 양수 숫자로 검증
8. 승인 및 활성 상태의 업체만 입찰 가능하도록 검증
9. 동일 업체가 같은 견적에 중복 입찰하는 것을 차단
10. 입찰 성공 시 고객 알림 유지

아직 실제 브라우저/Render에서 E2E 확인하지 않은 항목은 정상으로 표시하지 않는다. 다음 점검 대상은 고객의 입찰 선택 API와 업체 관리자 매장/사진/상담 권한 흐름이다.
