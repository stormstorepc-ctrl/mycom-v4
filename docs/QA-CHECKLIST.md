# MYCOM V4 업체 기능 QA 체크리스트

## 예약
- [ ] 예약 생성 시 업체가 승인/활성 상태인지 검증
- [ ] quote_id가 현재 로그인 고객의 견적인지 검증
- [ ] bid_id가 해당 quote에 속하고 선택 가능한 입찰인지 검증
- [ ] 과거 날짜 예약 차단
- [ ] 동일 시간 중복 예약 방지
- [ ] 취소 시 고객/업체 양측 알림 생성
- [ ] 상태 변경 시 권한 검증

## 입찰
- [ ] 동일 업체의 동일 견적 중복 입찰 차단
- [ ] 금액은 양의 숫자이며 합리적인 범위인지 검증
- [ ] 견적이 종료/취소된 경우 입찰 차단
- [ ] 업체가 승인/활성 상태인지 검증
- [ ] 고객에게 새 입찰 알림
- [ ] 고객이 입찰을 선택하면 업체에 알림

## 업체 관리자
- [ ] 내 매장관리 정보 조회/수정
- [ ] 대표사진 변경
- [ ] 사진 추가/삭제
- [ ] 예약 목록 및 상태 변경
- [ ] 상담방 목록 및 메시지
- [ ] 알림 읽음 처리
- [ ] 타 업체 데이터 접근 차단

## 고객
- [ ] 내 견적만 조회
- [ ] 내 예약만 조회/취소
- [ ] 내 상담방만 접근
- [ ] 업체 상세 → 상담/예약 연결
- [ ] 예약 완료 후 후기 작성

## 관리자
- [ ] 회원관리
- [ ] 업체 승인/거부
- [ ] 업체 정보 관리
- [ ] 예약/상담 현황
- [ ] 관리자 외 접근 차단

> 이 문서는 기능을 수정할 때마다 실제 API → DB → UI 흐름을 기준으로 갱신한다.
